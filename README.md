Overview: 
ReadMe's are present in each zip file and contain instructions for using the software to obtain the results from the raw data.

CURCI-G contains the data and analysis for the primary dataset
CURCI-G procrustes contains data and analysis for procrustes transformed primary dataset
CURCI-NG contains data and analysis for supplementary replication experiment
R figure script contains the script that was used to create figures.

Software Used:
Jasp 0.18.3.0 for analysis
RStudio 2024.04.1 for figures
Matlab R2025b for procrustes transformation
Spyder 5.4.3 for python scripts

Feel free to reach out with any questions.
